# 投标资格补充规范化说明

## 目标

投标资格补充不再使用一个自由文本框，也不再采用“内容非空即 PASS”。系统先把公告中的复合资格段落拆成独立要求，再为每条要求生成结构化字段并执行确定性核验。

## 当前支持的原子要求

- 企业主体与营业执照；
- 企业资质或行政许可；
- 同类项目业绩；
- 项目负责人及人员证书；
- 负责人、控股及管理关系；
- 信用与失信记录；
- 联合体要求。

## 三态规则

- 必填字段缺失、格式无法识别：`UNKNOWN`；
- 明确低于公告数量、等级、有效期或布尔约束：`FAIL`；
- 字段完整且未发现规则冲突：`PASS`。

`PASS` 仅表示用户提交的结构化声明通过当前规则核验，系统不会把它表述为已完成外部真实性审核。

## 数据绑定

每份补充严格绑定：

```text
企业 + 项目 + 原子资格要求
```

补充一条要求不会改变其他项目或其他要求。
