# 企业画像与投标决策统一改造验收报告（V3 前端修复）

验收日期：2026-07-31  
目标平台：Windows 10/11，本机单用户

## 本轮修复范围

本轮不修改企业画像后端评价规则、指标权重、总分或等级，只修复现场测试发现的前端问题：

1. 投标组合和 AI 说明不再向用户展示 `db-project-*`、`portfolio_rank`、`original_rank` 等内部标识；
2. 最终决策改为按真实项目名称展示的结构化卡片；
3. 主按钮、次按钮、危险按钮和禁用按钮使用明确的前景色与背景色；
4. 竞争分析从投标决策页拆出，点击后在新标签页打开独立详情页；
5. 删除同页向下滚动显示竞争分析的交互；
6. 企业评价前端恢复为原有分区式工作台结构，同时保留真实企业数据路径和已删除演示入口的约束；
7. 企业画像后端评分规则继续冻结，并以 SHA-256 完整性清单验证未被修改。

## 企业画像边界说明

- 企业画像**后端**评价规则、权重、总分和等级完全未修改；
- 企业画像前端不再沿用本轮误加的简化重设计，恢复原有工作台式结构；
- 为满足已确认的数据原则，前端仍不会恢复 Mock、Fixture、Replay、演示审核、测试数据重置或伪用户入口；
- 企业原始 JSON 继续只读，运行结果和补充数据仍单独保存。

## 投标决策前端结果

正常业务页面只展示：

- 项目名称；
- 组合排名；
- 客观基础分；
- 资格状态；
- 本次偏好匹配；
- 中文决策结论；
- 未入选原因和资源冲突。

内部项目 ID 仅允许存在于接口参数、路由参数、持久化记录和技术日志中，不作为普通用户文案展示。

## 前端构建环境说明

`vue-tsc -b` 已通过。当前 Linux 验收容器的 Vite 产物打包仍受已有依赖缺少 Rollup Linux 可选原生包 `@rollup/rollup-linux-x64-gnu` 阻挡。失败发生在 Vite/Rollup 启动阶段，不是 Vue 模板、TypeScript 或业务逻辑错误。

交付目标为 Windows。目标机器执行干净的 `npm ci` 时，应安装对应 Windows 平台的 Rollup 可选依赖。交付 ZIP 不包含当前 Linux `node_modules`。

## Windows 现场复核项

1. 保持 SSH 隧道窗口运行；
2. 使用新目录和原有本机 `.env.local` 运行 `start.ps1`；
3. 新建投标决策任务；
4. 检查最终组合只显示真实项目名称；
5. 检查所有按钮文字清晰可见；
6. 点击“查看竞争分析（新标签页）”，确认浏览器打开独立页面；
7. 检查企业评价工作台的原有分区式结构和评分结果。
